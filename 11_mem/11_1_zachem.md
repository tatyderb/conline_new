# Зачем нужна динамическая память

## Уже знаем

Мы не задумывались раньше, что происходит с памятью, когда мы объявляем переменные и как эта память освобождается, когда время жизни переменной заканчивается.

```cpp
int foo(int k)                      // выделяется память для переменной k
{
    int x = 7;                      // выделяется память для переменной x
    int a[5] = {-1, 2, -3, 4, -5};  // выделяется память для переменной a
    int * p = a+2;                  // выделяется память для переменной p
    
    return x + a[k] + p[0];
    // освобождается память, занятая переменными k, x, a, p
}

int main()
{
    int b;                          // выделяется память для переменной b
    b = foo(0);
    b += foo(2);
    printf("%d\n", b);
    
    return 0;
    // освобождается память, занятая переменной b
}
```
Менеджер памяти делает большую работу без нас. Мы ее не видим. Когда обычной незаметной работы с памятью не хватает и нужно выделять память динамически?

* Нестандартные структуры данных, например, треугольную матрицу, а не прямоугольную.
* Во время работы программы нужно изменить размер массива (пришло больше данных).
* Нужно вернуть из функции указатель на локальную переменную.
* Определить размер массива на этапе выполнения программы, а не компиляции. 

## Чтение последовательности чисел

В задачах обычно последовательность чисел задается так: "Дано n, далее n чисел". Например:

```cpp
5
2 -3 16 31 -10
```

### n < 1000

Если последовательность надо сохранить в массиве, то до стандарта **С99** размер массива должен был задаваться на этапе компиляции. Ограничение на размер массива давалось в условии задачи. Например, $n < 1000$.

```cpp
#define N 1000

int a[N];   // массив, размер задаем на этапе компиляции
int n;      // сколько чисел дано
int i;

scanf("%d", &n);            // дано n
for(i = 0; i < n; i++)
    scanf("%d", a+i);       // вместо a+i можете писать &a[i]
```

### Стандарт C99

**Начиная с С99 можно определять длину массива на этапе выполнения.** *На проверяющих серверах [ejudge МФТИ](https://stepik.org/lesson/308220/step/3) это запрещено.*

```cpp
int n;              // сколько чисел дано
scanf("%d", &n);    // прочитали n
int a[n];           // объявили массив, размер n задаем на этапе выполнения программы

for(int i = 0; i < n; i++)
    scanf("%d", a+i);
```

### Выделяем динамическую память

До С99 нужно было писать так:
```cpp
int n;                                  // сколько чисел дано
scanf("%d", &n);                        // прочитали n
int * a = malloc(n * sizeof(int));      // сами выделили динамическую память         

for(int i = 0; i < n; i++)
    scanf("%d", a+i);
    
free(a);                                // сами освободили память после использования        
```
Для работы **malloc** и **free** нужно подключить `stdlib.h`

* `void *` **malloc** `(size_t size);`
    * выделить **size** байт памяти,
    * возвращает указатель на выделенную память.
*  `void` **free** `(void *ptr)`;
    * освободить память, на которую указывает **ptr**

## n не задано

Если **n** не дано, а задана только последовательность чисел, то читаем все числа, используя [scanf](https://stepik.org/lesson/604863/step/2)

Даны числа. Найти их сумму.
```cpp
2 -3 16 31 -10
```
Решение:
```cpp
int x, sum = 0;

while(1 == scanf("%d", &x))     // пока читаем еще одно число
    sum += x;
    
printf("%d\n", sum);
```

### Количество чисел ограничено

Пусть числа надо прочитать в массив `a`. Какого размера объявить массив? Если известно, что чисел не больше 100, то `int a[100];`

Если заранее количество чисел неизвестно, то будем изменять размер выделенной памяти, добавляя память по 1 элементу массива, то есть `+sizeof(int)` байт.
