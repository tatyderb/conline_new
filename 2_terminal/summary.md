## Компиляция и запуск

Команды для компиляции программы из файла `hello.c` в файл `hello.exe` (исполняемый модуль) и запуск этого файла в командной строке Unix:
```cpp
gcc -Wall -Wextra -o hello.exe hello.c
./hello.exe
```
По умолчанию исполняемый модуль - файл `a.out`:
```cpp
gcc -Wall -Wextra hello.c
./a.out
```
