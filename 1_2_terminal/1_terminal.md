## Создадим файл hello.c с текстом программы

**Если вы не устанавливали программы и хотите пока работать в онлайн редакторе Степика, рекомендуем пропустить этот модуль и сразу перейти к [первым программам](https://stepik.org/lesson/571830/step/1?unit=566369). Вернетесь сюда, когда писать в онлайн-редакторе станет неудобно и придется установить программы.**

**Баллы за сертификат с отличием настроены так, что не требуют прохождения этого модуля.**

Цель этого модуля: 

* создать файл `hello.c` с текстом программы,
* запустить терминал, 
* перейти в директорию с этим файлом, 
* скомпилировать программу,
* запустить полученный файл `hello.exe`.


В текстовом редакторе или среде разработке, которые вы установили, создайте файл `hello.c` и сохраните его на диск. Запомните или запишите путь, где лежит файл.

Не знаете куда вы его положили? Обычно в любых редакторах или IDE в меню `File` (Файл) есть пункт `Save As` (Сохранить как). Сохраните куда вам нужно.

Удобнее, если **в именах директорий по пути к файлу будут только латинские буквы и не будет пробелов**.

Откопируйте или перепишите в файл текст программы, которая печатает `Hello, world!`:

```cpp
#include <stdio.h>              // использовать стандартные функции ввода-вывода

int main()                      // здесь начинается программа
{
    printf("Hello, world!");    // печать строки Hello, world!
    
    return 0;                   // конец программы
}
```

**Важно! Расширение файла должно быть `.c` (латинская буква c)**

Например, я работаю в Windows и мой файл лежит в `C:\work\stud\conline\1int\hello.c`

Ваш файл может лежать в другом месте и называться по-другому.

**Задание**: Создайте файл с текстом программы. Запишите (у себя на бумажке), где он находится.

## Разница между путями Windows и Linux

Путь в Windows: `C:\work\stud\conline\1int\hello.c`

* есть диски C, D, и так далее, сколько установили. От диска начинается полный путь.
* директории разделены `\`

Путь в Linux: `/home/taty/conline/1int/hello.c`

* нет дисков, путь начинается от корня `/`
* директории разделены `/`

Напоминаем, диск С Windows в wsl находится в `/mnt/c`

Фрагмент дерева директорий и файлов в Linux (WSL):
```cpp
/
├── bin
│   ├── cd
│   ├── ls
│   ├── pwd
│   ...
├── home
│   ├── tatyd                               <-- моя домашняя директория
│   ...
├── mnt
│   ├── c
│   │   ├── Users
│   │   │   ├── tatyd                       <-- я сейчас тут
│   │   │   └── другие директории и файлы
│   │   └── work
│   │       └── stud
│   │           └── conline
│   │               ├── 1int                <-- нужно перейти сюда
│   │               │   └── hello.c         <-- файл с текстом программы
│   │               ├── 2func
...
```

## Абсолютный и относительный путь

### Абсолютный путь

* В Linux **начинается с `/`**
    * Примеры абсолютного пути в Linux:
```cpp
/home/taty/conline/1int/hello.c
/mnt/c/work/stud
```

* В Windows **начинается с имени диска и после имени диска идет `\`**
    * Примеры абсолютного пути в Windows:
```cpp
C:\work\stud\conline\1int\hello.c
D:\games\tetris.exe
```

### Относительный путь 

Задается относительно текущей директории (мы в ней находимся). Любой путь, который не абсолютный, будет относительным.

* `..` - **родительская директория** (на 1 директорию вверх)
* `.` - **текущая директория**

Примеры относительного пути в Linux:
```cpp
hello.c
work
conline/1int/hello.c
./a.out
..
../../img
```

Примеры относительного пути в Windows, если путь начинается с `\`, то он задается относительно текущего диска:
```cpp
hello.c
work
conline\1int\hello.c
.\a.exe
..
..\..\img
\work\hello.c
```

## Запустить терминал

Если у вас Linux или MAC, то запустите любой терминал.

В Windows запустите установленную WSL или cygwin.

Запуск WSL (номер версии Ubuntu у вас может быть другой):

![Start WSL](https://stepik.org/media/attachments/lesson/562181/start_wsl.png)

или нажмите **Win+R** и в полученном поле наберите `wsl` и нажмите клавишу Enter.

Откроется окно, в котором мы будем писать команды.

В окне обычно есть приглашение на ввод, где написано 
```cpp
имя_пользователя@название_компьютера:текущая_директория$
```
Приглашение на ввод можно настроить самим. 

Пример окна Ubuntu и WSL на Windows:
![terminal](https://stepik.org/media/attachments/lesson/562181/terminal.png)
