
## Когда объявлять переменные

Язык Си изменяется. Время от времени принимаются новые **стандарты языка**. В них добавляют новые возможности и иногда изменяют старые принципы. 

Давным-давно (сейчас эти стандарты вы вряд ли найдете), требовалось сначала объявить все переменные, и только потом использовать их. Это удобно, когда программа небольшая. Сначала идет блок объявления переменных и вы читаете, с чем работает программа.

В современном программировании принято объявлять переменную там, где она потребовалась. Не обязательно в начале.

```cpp
#include <stdio.h>

int main()
{
    float m;    // масса, кг 
    float h;    // рост, м
    
    // читаем входные данные
    scanf("%f%f", &m, &h);
    
    float imt = m / (h * h);        // обявляем переменную и сразу присваеваем ей значение

    printf("%f\n", imt);
    
    return 0;
}
```
Можно было вообще обойтись без переменной `imt`:
```cpp
    printf("%f\n", m / (h * h));
```



## Разные стандарты

Различные версии языка Си закреплены в стандартах языка. 

[Версии языка Си](https://ru.wikipedia.org/wiki/%D0%98%D1%81%D1%82%D0%BE%D1%80%D0%B8%D1%8F_%D1%8F%D0%B7%D1%8B%D0%BA%D0%B0_%D0%A1%D0%B8):

| Версия | Описание |
|----|----------|
| `K&R C` | 1978 год, первая версия языка, названа по авторам Brian Kernighan и Dennis Ritchie. Ритчи сконструировал язык и написал компилятор. Керниган был соавтором известной книги (первой!) по языку Си. |
| **C89**, ANSI C, C90 | В 1989 году American National Standards Institute (ANSI) утвердил стандартную спецификацию языка. В 1990 году с небольшими изменениями она была так же принята International Organization for Standardization (ISO), известна как С90 |
| C95 | Редко упоминаемый стандарт |
| **C99** | Добавлено достаточно много новых вещей, например, комментарии в одну строку `//`. Самая популярная версия языка. В курсе мы придерживаемся, в основном, её. |
| **C11** | Следующее популярное обновление. Добавлена поддержка unicode и многопоточность. Если ANSI C работает на любом компиляторе, С99 - почти везде, то в некоторых системах еще нет поддержки С11. |
| C17 | В спецификациях тоже существуют ошибки. С17 - это исправление ошибок спецификации С11. Опубликован в 2018 году, но называется все же С17. |
| C2x | Ждем. Скорее всего о нем будет написано "называется С21, но выпущен в ...". Существенных изменений нет. |

В gcc можно указать, по какому стандарту компилировать программу, указав ключ **-std**. Например, указать явно С99 можно так:

```cpp
gcc -Wall -Wextra -std=c99 -pedantic foo.c
```
На [stepik](https://stepik.org/lesson/59057/step/13?unit=36621) приняты следующие ключи для компиляции задач на Си:

* C (gcc 6.3.0, C99 Standard)
    * Compile command: `gcc -std=c99 -pipe -O2 -static -o main -lm`
* C (Valgrind) (gcc 6.3.0, C99 Standard)
    * Compile command: `gcc -std=c99 -pipe -O0 -o main -lm -ggdb3`
    * Run command: `valgrind -q --track-origins=yes --malloc-fill=66 --free-fill=66 --leak-check=full --error-exitcode=1`
