## Пример: ИМТ

* **float** - тип для работы с десятичными дробями, например 3.14.
* **%f** - формат для чтения и печати десятичных дробей (значений переменных типа float).
* `/` - оператор деления в языке Си.

В примере вычисляют и печатают индекс массы тела человека (ИМТ) по формуле Кетле $$k = m / h^2$$ где $m$ - масса в кг, $h$ - рост в метрах.

Сначала придумаем, на каких данных будем проверять - правильно работает программа или нет. Это называется **тестовые данные**. Старайтесь первые данные брать такие, которые просто проверить, считая "в уме". Возьмите "сложный случай" и не забудьте проверить "вырожденные случаи".

| Масса, кг | Рост, м | ИМТ | Комментарий |
|----|----|----|-----|
| 45 | 1.5 | 20 | Эти тестовые данные мы делали "от результата". Взяли ИМТ = 20, взяли *нецелый* рост, который легко возводится в квадрат, получили массу |
| 52.65 | 1.5 | 23.4 | Взяли нецелое ИМТ и тот же рост. Теперь масса - не целая. |
| 83 | 1.75 | 27.1020408163265 | Целая масса, дробный рост |
| 73.124 | 1 | 73.124 | Полезный тест, если он будет один верный, а предыдущие - нет, то ошибка в возведении в квадрат |
| 0 | 0.9 | 0 | Еще один тест на "вырожденные случаи". Печально, если и этот тест будет неверный |
| 134.67 | 2.18 | 28.3372611733019 | Случайно придуманные тестовые данные, чтобы все числа были не целыми |

Программа:
```cpp
#include <stdio.h>

int main()
{
    float m;    // масса, кг 
    float h;    // рост, м
    
    float imt;  // индекс массы тела (формула Кетле)
    
    // читаем входные данные
    scanf("%f%f", &m, &h);
    
    // вычисления
    imt = m / (h * h);

    printf("%f\n", imt);
    
    return 0;
}
```

Чуть позже, сразу после решения задач, мы рассмотрим как хранятся в памяти компьютера целые числа и числа с плавающей точкой. Почему возникает погрешность.

Проверяющая система умеет сравнивать с указанной (авторами) точностью. Не беспокойтесь, если ваша программа печатает чуть другое значение, чем указано в примерах ввода и вывода. По умолчанию, требуется точность 0.0001.

## Термины и арифметические операции

Чтобы понимать объяснения, разберемся, какие термины используют для описания работы арифметических операций.

* **операция** - из математики знаем операции сложения, вычитания, умножения, деления.
* **операнд** - это знак операции, (для сложения +, для вычитания - и так далее).
* **оператор** - аргумент операции, в зависимости от аргументов операции делятся:
    * по количеству аргументов:
        * **бинарные операции** - два аргумента, например, `5+2`, `24-8`.
        * **унарные операции** - один аргумент, например, унарный минус в операции `-5` или `-x`.
        * в Си есть операции с [3 аргументами](https://stepik.org/lesson/257934/step/3).
    * где пишется аргумент:
        * **инфиксный оператор** - между операторами, например `2+3`.
        * **префиксный оператор** - перед оператором, например `-x`.
        * **постфиксный оператор** - после оператора, например `x++` (позже расскажем про него в этом уроке).


| Выражение | Результат | Объяснение |
|----|----|---------|
| `2 + 3` | `5` | сложение |
| `5 - 3` | `2` | вычитание |
| `5 * 3` | `15` | умножение |
| `7 / 2` | `3` | деление |
| `7.0 / 2.0` | `3.5` | тоже деление |
| `7 % 2` | `1` | остаток от деления (только целочисленные операнды)|
| | | **НЕТ операции "возведение в степень"** |

Математики в шоке, делим 7 на 2 и получаем то 3.5, то 3?

В языке Си если **операторы** в арифметическом выражении **целого типа**, то **результат** этого выражения тоже **целого типа**.

* `7.0 / 2.0` - оба операнда дробные, результат тоже дробный, то есть `3.5`.
* `7 / 2` - оба оператора целочисленные, значит результат тоже целое число. **Целое число получается из дробного отбрасыванием целой части**. То есть результат `3`.

Когда мы переводили рост из сантиметров в метры в `hsm / 100` мы делили одно целое число, например, 150 или 175, на другое целое число 100 и получали 1. 

Что будет, если одно целое, другое - нет? Оба целых, но есть отрицательные числа?

### Деление и остаток от деления для отрицательных чисел

| выражение | результат | выражение | результат |
|----|----|----|----|
| `7 / 2` | `3` | `7 % 2` | `1` |
| `-7 / 2` | `-3` | `-7 % 2` | `-1` |
| `7 / -2` | `-3` | `7 % -2` | `1` |
| `-7 / -2` | `3` | `-7 % -2` | `-1` |

Внимание! Если вы изучали python, то в [python](https://tirinox.ru/divide-modulo-python/) остаток всегда того же знака, что и делитель и `-7 // 2` будет `-4` с остатком `1`. В языке Си это не так.

## Операнды разных типов

Если операнды разных типов, то они **автоматически приводятся к одному типу**, в нем выполняется операция и получается результат.

При вычислении `7.0 / 2`:

* 2 приводится к нецелому типу
* в нем производится вычисление, получается 3.5

## Порядок вычислений

При разборе преобразований типов важно учитывать порядок вычислений и тип операндов в выражении.

```cpp
float x = 7 / 2;   // x = 3.0
```
* в выражении `x = 7 / 2` сначала вычисляется значение правой части:
    * вычисляем `7 / 2`, оба значения int, значит результат int, то есть 3. 
* результат 3 записывается в переменную `x`, которая типа `float`, при этом происходит **неявное** преобразование типа к float.

Порядок вычислений определяется приоритетом операций. В выражении `1 + 2*3 + 4` сначала вычисляется умножение `2*3`. Как в математике, скобки изменяют порядок вычислений. В `2 * (3+4)` сначала вычисляется `3+4`.

## Операция приведения типа (type cast)

Чтобы в `x` записалось 3.5 нужно в выражении `float x = 7/2;` сделать делимое или делитель не целым типом. Например:
```cpp
float x = 7.0 / 2;
```
Что делать, если числа 7 и 2 - это значения целочисленных переменных?
```cpp
int a = 7, b = 2;
float x = a / b;    // 3.0, нужно 3.5
```
Для этого используется операция **(тип)** приведения типа. Её приоритет выше, чем у арифметических операторов. Поэтому можно писать так:
```cpp
int a = 7, b = 2;
float x = (float)a / b;    // 3.5, ибо сначала значение a (число 7) привели к типу float, потом начали делить
```

В отличие от python, пишется `(int)3.14`, потому что в Си приведение типа - это оператор, а не функция.
