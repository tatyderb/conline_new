## TASKINLINE Escape-последовательность

Набор символов из `\` и 1 символа или нескольких цифр называют экранированной последовательностью (escape sequence). Потому что `\` экранирует обычное значение символа.

* `n` - буква n
* `\n` - символ новой строки, значение "буква n" заменяется значением "новая строка".
```
printf("Hello, world!\n");  // после текста курсор - на новую строку
```

![](https://stepik.org/media/attachments/lesson/403576/new_line.png)

| Escape последовательность | Значение |
|----|------|
| `\n` | новая строка (курсор на первую позицию следующей строки) |
| `\r` | возврат каретки (курсор на первую позицию этой строки) |
| `\t` | табуляция |
| `\'` | `'` |
| `\"` | `"` |
| `\\` | `\` |
| `\%` | `%` |

*На Stepik `\r` работает как `\n`. Возврат каретки на предыдущую позицию (backspace) `\b` на Stepik работает как пробел. 
Это не баг, а фича (с), Stepik такое поведение исправлять не будет.*

Символ `"` начинает и заканчивает строковую константу (текст). Поэтому если я хочу написать `Мне нравится фильм "Титаник"`, то в выражении
```cpp
printf("Мне нравится фильм "Титаник".\n");
```
компилятор решит, что строковая константа это `"Мне нравится фильм "` (эти кавычки заканчивают строковую константу!), а дальше идет непонятно что. Ошибка.

Чтобы заменить специальное значение символа `"` (начало или конец строковой константы) на _просто символ кавычки_, нужно экранировать его специальное значение.

```cpp
printf("Мне нравится фильм \"Титаник\".\n"); // работает
```

## Длинная строка

Если нужно написать длинную строку, то не обязательно вытягивать ее в одну строку. Можно экранировать перевод строки.

```cpp
printf("Этот текст \
будет напечатан в одну строку.\n");
```

Знак `\` должен быть последним символом в строке.

## Что такое табуляция?

Представьте, что в текстовом редакторе через каждые N символов проведена невидимая вертикальная линия. При нажатии на клавишу TAB курсор помещается на место ближайшей правой линии.

Размер табуляции настраивается в текстовых редакторах и терминалах.

Если ширина табуляции 4, то 
```cpp
printf("ab\t12345\tz\n");
printf("<\t<\t<\t<\n");
```
напечатает
```cpp
ab  12345   z
<   <   <   <
```

## Много строк

Если нужно напечатать стихотворение или хелп по программе. Это много строк. Как сделать лучше?

### Вариант 1. "В лоб". 

Одна строка - один `printf`.

Не забываем ставить `\n` в конце для перевода строки.

```cpp
#include <stdio.h>
int main()
{
    printf("Я помню чудное мгновенье:\n");
    printf("Передо мной явилась ты,\n");
    printf("Как мимолетное виденье,\n");
    printf("Как гений чистой красоты.\n");
    return 0;
}
```

А можно в один `printf`? Можно.

### Вариант 2. Одна длиииииииннная строка

Но [не рекомендуют](https://stepik.org/lesson/2464060/step/3) писать код после 80 позиции в строке. Такое неудобно читать.

### Вариант 3. Один printf на несколько строк

Если написать между двумя строковыми константами в программе только пробельные символы (пробел, табуляция, новая строка и тп), то эти строки склеятся в одну.

Оба варианта напечатают одно и то же:

```cpp
printf("Hello, world!");                 // Hello, world!
printf("Hel"  "lo, wor"         "ld!");  // Hello, world!
```
Стихотворение:
```cpp
#include <stdio.h>
int main()
{
    printf(
        "Я помню чудное мгновенье:\n"
        "Передо мной явилась ты,\n"
        "Как мимолетное виденье,\n"
        "Как гений чистой красоты.\n"
        );
    return 0;
}
```

## 🎓 Символ конца строки

В Си нет такого символа. Конец строки (EOL, End Of Line) - это способ кодировать текст в текстовом файле. Если вы пишете программы не в браузере, то в вашем редакторе наверняка можно выбрать, как кодировать конец строки в файле.

Кодировка изначально зависела от операционной системы.

* В UNIX было принято ставить `\n` в конце строки.
* В MAC было принято ставить `\r`.
* Когда создавали DOS, решили в конце ставить символы так, чтобы они правильно читались и в UNIX, и в MAC. И поставили в конце **два символа** `\r\n`. Windows - наследник DOS, поэтому в Windows символ конца строки `\r\n`.

Варианты выбора EOL для открытого файла в программе Notepad++:

## 🎓 `\r` и `\n`

Почему разные символы `\r` и `\n`? Нельзя было обойтись одним? Исторически сложилось, что это два разных действия.

Ввод символов в компьютере и их печать происходит на экране там, где находится **курсор**.

* `\n` - New Line (NL) или Line Feed (LF) - перевод каретки пишущей машинки (а сейчас курсора) на новую строку.

* `\r` - Carriage Return (CR) - возврат каретки пишущей машинки (а сейчас курсора) на первую позицию текущей строки.

В механической пишущей машинке можно было прокрутить валик вверх, чтобы перевести позицию печати на новую строку (New Line), а можно было вернуть валик влево, тогда позиция печати оставалась на той же строке. Обычно дерганье рычага валика сразу и переводило на новую строку, и перемещало валик вправо, в начало строки.

## Многострочные комментарии

* От `//` до конца строки - однострочный комментарий.
* От `/*` до `*/` - блочный комментарий - можно писать комментарий на одну или несколько строк.

```cpp
#include <stdio.h>  // однострочный комментарий

// Можно написать
// несколько однострочных комментариев подряд
int main()
{
    /* Можно написать
       многострочный комментарий
       вот так.
    */
    printf("Hello\n");
    /* Или написать комментарий в одну строку */
    return 0;
}
```

💥 **Нельзя писать вложенные блочные комментарии.**

Комментарием считается от первого встречного `/*` до первого встречного `*/`.

```cpp
// можно внутри него написать /* вложенный блочный */ и что-то ещё
#include <stdio.h>

int main()
{
    /* Начало внешнего комментария.
       Можно написать
       блочный комментарий
       // и внутри однострочный комментарий
       /* Нельзя писать 
          вложенный блочный комментарий.
          ОШИБКА.
       */ конец внешнего комментария будет здесь
       а не ниже...
    */
    printf("Hello\n");
    return 0;
}
```

## Итого

### Комментарии

Комментарий - это код "для человека, а не для компьютера". Он удаляется из программы до компиляции.

* От `//` до конца строки.
* От `/*` до `*/`, может быть на несколько строк - блочный комменрарий.
* Нельзя написать вложенный блочный комментарий.

### Управляющие последовательности (escape sequence)

| Escape последовательность | Значение |
|----|------|
| `\n` | новая строка (курсор на первую позицию следующей строки) |
| `\r` | возврат каретки (курсор на первую позицию этой строки) |
| `\t` | табуляция |
| `\'` | `'` |
| `\"` | `"` |
| `\\` | `\` |
| `\%` | `%` |
