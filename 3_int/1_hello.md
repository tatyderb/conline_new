## Разбор программы Hello, world!

Пока мы будем брать образец программы на Си и менять в нем часть кода. Что делает остальной код, разберем подробно на следующем уроке.

Вы копировали код программы. Далее вы будете писать новый код. Обучение невозможно без ошибок. Если вы изучаете первый язык, полезно будет самому специально сделать ошибку и посмотреть на диагностику компилятора об этой ошибке. Проще понять, о чем диагностика.

Работаем с ошибками:

    * делаем ошибку в коде,
    * сохраняем файл с кодом программы (в текстовых редакторах есть сокращения для команд, обычно для сохранения файла это **Ctrl+S**),
    * переходим в терминал (**Alt+TAB**),
    * компилируем с помощью gcc и смотрим на диагностику,
    * исправляем эту ошибку в текстовом редакторе,
    * делаем другую ошибку в коде и повторяем эти шаги.
    
В коде должна быть только одна ошибка, иначе одна ошибка может спрятать другую.

Зачем сохранять файл после изменения кода в нем? Запись изменений файла на диск - долгая операция. Если бы редакторы каждое изменение в тексте сразу сохраняли на диск, то они бы работали медленно. Поэтому они держат копию файла в памяти и изменяют эту копию. Иногда сохраняют данные из памяти на диск (это обычно пункт меню File / Save).

Если ваш текстовый редактор находит и выделяет ошибку, можно посмотреть на его обозначение ошибки и не выполнять эту длинную инструкцию "сохранить - перейти - скомпилировать - исправить ошибку".

## Разберем программу

Программа:
```cpp
#include <stdio.h>              // использовать стандартные функции ввода-вывода

int main()                      // начало программы
{
    printf("Hello, world!");    // печать строки Hello, world!
    
    return 0;                   // конец программы
}
```

Обратите внимание, что в программе три разных типа скобок: 

* `<>` в первой строке, 
* `()` у функций 
* `{}` один раз

## `#include <stdio.h>`

* `#include <stdio.h>` - включить в программу информацию для чтения и печати данных.
    * `#` - с этого знака "диез" начинаются все команды препроцессора
    * команда препроцессора `include` (англ. "включить")
    * скобки `<>`
    * включаем мы файл, в котором описан **st**an**d**ard **i**nput/**o**utput (стандартный ввод/вывод)
    * не забываем, расширение этого файла `.h`
    
Сделаем ошибки:

* забудем `#`
* неверно напишем `include`
* неверно напишем `stdio.h`
* напишем другие скобки вместо `<>`

Заметьте, если написать без пробелов `#include<stdio.h>`, то это компилируется без ошибок и работает.
    
## `int main() { }`

* Программа всегда начинает выполнение с функции **main** (англ. "главная").
* Перед названием функции пишем `int` от слова **int**eger.
* Дальше `()`
* Дальше `{}`. Внутри этих скобок мы будем менять код на этом уроке.

Сделаем ошибки:

* неправильно напишем `main`
* Забудем обе или одну из `()`
* Забудем `{`
* Забудем `}`
* Напишем без пробела `intmain`

Заметьте, количество пробелов или переводов на новую строку в этой конструкции не приводит к ошибкам.

## `printf("Hello, world!");`

* **print+f**ormat - печать по формату, стандартная функция языка С для вывода на печать,
* `printf` функция, ее аргументы надо писать в `()`, как в математике,
* текст пишем в `"`
* в конце пишем `;`

В русском языке в конце каждого предложения ставим точку. В языке Си в конце каждой мысли ставим `;`

Сделаем ошибки:

* забудем f в `printf`,
* забудем одну из `()` или сразу обе,
* напишем только одну `"`,
* напишем вместо двойных кавычек `"` одинарные кавычки `'`,
* забудем `;`

Заметьте, что `;` мы забыли на одной строке, а компилятор показывает, что ошибка на следующей, нужен `;` **перед** указанным кодом.

## `return 0;`

* **return** (англ. "вернуть") - ключевое слово языка Си, запомните его.
* Дальше любое целое число,
* `;` в конце мысли.

Сделаем ошибки:

* напишем неправильно слово `return`
* напишем без пробела `return0`
* забудем написать 0
* забудем написать `;`

Заметьте, можно написать вместо 0 любое целое число и программа будет по-прежнему компилироваться и работать.

## Пробелы и переводы строк

Компилятор разбивает текст вашей программы на понятные ему слова и понимает их. Компилятор - это программа, ему все равно написан ваш код в одну строку, или красиво отформатирован (правильно расставлены пробелы и переводы строк).

Преподаватель и ваши будущие коллеги - это не бездушные программы, а живые люди. Им удобнее читать красиво отформатированный текст.

Мы стараемся форматировать текст курса, чтобы его было удобно читать. 

Пишите программы так, чтобы их было всем удобно читать. Зачем?

* преподаватель будет проверять как написана ваша программа. Это называется **code review**. Во всех хороших командах программистов код одного человека просматривает другой человек.
    * можно увидеть неочевидную ошибку в логике программы,
    * замечания по коду сделает ваш код лучше и повысит вашу квалификацию.
    
Представим, я делаю задание по математике и оно написано нечитаемо.

* преподаватель не может его проверить, 
* я не могу разобраться в старом решении,
* никто не может найти ошибку в решении, проще решать заново.

Код должен быть читаем. Ставьте пробелы и переводы строк.
