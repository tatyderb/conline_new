## Что нужно установить

Для учебы нужно:

* текстовый редактор, в котором будем писать текст программы и создавать файлы с тестовыми данными,
* командная строка Linux/MAC,
* компилятор,
* инструмент для отладки работы с памятью `valgrind`,
* отладчик (опционально, можно пройти курс без него, используя отладочную печать - основной инструмент для поиска ошибок в программе в этом курсе).

Выберем набор программ для установки, исходя из возможностей вашего компьютера и операционной системы, которая на нем стоит.

* Если у вас возник технический вопрос по установке, задайте его в вашем канале общения с преподавателем или напишите в комментариях к шагу.
* Если вы нашли ответ на частую проблему, напишите ссылку на решение или опишите решение.

## Вопрос: может поставить мощную IDE, где есть сразу все?

Для новичков главное простота и удобство использования. Только нужные функции и ничего лишнего.

Мы не рекомендуем начинающим использовать IDE (Clion, MS VS или XCode). В курсе надо написать много маленьких программ. IDE предназначены для длительной работой над 1 программой, расположенной в нескольких файлах.

* Много функционала, которые не нужны начинающим, в нем легко запутаться.
* компиляцию и запуск с параметрами из командной строки трудно найти, очень будет нужно, когда начнутся задачи с большими тестовыми данными, например, сортировка большой входной последовательности.

Нам хватит текстового редактора с показом номеров строк и подсветкой синтаксиса языка.

## Командная строка

Без командной строки тяжело запускать программу с большими тестами и нельзя будет запустить `valgrind`. Задача будет работать на вашем компьютере (без проверок valgrind) и не будет проходить проверку в курсе (valgrind показал ошибку). Тяжело найти ошибку в своем решении.

На Linux и MAC командная строка уже есть. Называется терминал. Переходите на следующий шаг.

На Windows нужно поставить командную строку Linux. Что ставить, зависит от версии Windows.

**Запишите и запомните свой логин и пароль при установке. Он понадобится на следующем шаге.**

* На Windows 10 рекомендуем установить **WSL** (Windows Subsystem for Linux) или **WSL2**. На нем можно делать задачи всех курсов МФТИ по С, в том числе курс по IPC. 
    * [Установка WSL на Windows 10](https://docs.microsoft.com/ru-ru/windows/wsl/install-win10)
    * [Установка WSL на Windows 10 еще одна инструкция](https://g-ek.com/kak-zapustit-bash-v-windows-10)
    * [Video]() - Нужно найти нормальное видео, желательно на русском.
* На Windows 7 или 8 установите **cygwin**. На курсе, изучающим IPC UNIX, `cygwin` будет не достаточно.
    * [cygwin](https://cygwin.com/install.html)
    * [Video](https://www.youtube.com/watch?v=2csABC85onI) - установка
    
В WSL могут быть проблемы с настройкой интернета. [Как настроить ssh в bash](https://superuser.com/questions/1111591/how-can-i-ssh-into-bash-on-ubuntu-on-windows-10)

## Компиляторы и инструменты отладки

Открыть **командную строку** и там набирать команды этого раздела.

Если вы установили `WSL` на Windows, то нужно выполнить следующие команды:
```cpp
sudo apt-get update
sudo apt-get install cmake gcc clang gdb build-essential
sudo apt-get install valgrind
```

Проверьте, что компилятор установлен:
```cpp
gcc --version
```
Должен быть напечатан номер установленной версии gcc.

## Где искать файлы Windows в командной строке Linux

* `\` - в Windows, `/` - в Linux,
* Из командной строки в **WSL** файл Windows `C:\work\hello.c` находится в `/mnt/c/work/hello.c`
    * диск Windows нужно искать в `/mnt/имя_диска`
* Из командной строки **cygwin** файл Windows `C:\work\hello.c` находится в `/cygdrive/c/work/hello.c`   
    * диск Windows нужно искать в `/cygdrive/имя_диска`

## Работаю на чужом компьютере, нельзя ничего установить

Тогда рекомендуем [replit.com](replit.com)

Выберите новый repl с языком С. В консоли вы найдете командную строку, `gcc` и `valgrind`. 

Там можно включить режим multiplayer и редактировать файл вместе с другом или преподавателем.
