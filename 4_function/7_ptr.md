## Байт и адрес

Память компьютера разбита на ячейки. У ячеек уникальные номера (**адреса**).

Минимальная единица памяти, которая имеет адрес, называется **байт**. Байт состоит из бит (0 или 1).

Переменная - это часть памяти, к которой обращаемся по имени. Например, переменная `x`.

Переменная может занимать 1 или больше байт непрерывно, одним куском. Например, если переменная расположена в байтах с адресами 100, 101, 102, 103, то **адрес переменной** - это адрес наименьшего байта, 100. Будем говорить, что "переменная x расположена (лежит) по адресу 100", чтобы не путать со "значение переменной х - это 7".

![Переменная расположена в нескольких байтах]() 

`int x = 7;` Пусть 100 - адрес переменной `х`. Будем изображать переменную, ее значение и адрес так:

![Переменная]() 

В прикладной программе мы не можем указывать по какому конкретному адресу нужно расположить данные и переменные. Этим занимается планировщик памяти в операционной системе. При разных запусках программы одна и та же переменная х может располагаться по разным адресам памяти.

Для удобства объяснения мы будем писать "пусть х расположена по адресу 100" или "пусть 100 - это адрес переменной х".

## Указатель

```cpp
int x = 7;  // переменная х типа int, ее значение 7
```
Пусть 100 - это адрес переменной х.

Переменная может хранить адрес. Тип такой переменной **указатель на** (pointer).

```cpp
int * p;    // переменная p типа "указатель на int". Пока никуда не указывает.
```
Есть операции **взять адрес** переменной `&`. Этот адрес можно сохранить в указателе.

```cpp
p = &x;
```
* `&x` - взяли адрес переменной `х`, это 100
